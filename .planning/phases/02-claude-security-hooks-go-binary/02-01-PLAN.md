## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code → hook process stdin | Trusted producer; structured JSON payload per code.claude.com/docs/en/hooks |
| Workspace filesystem → fsutil.go | Read-only access; agent-cited paths come from verdict JSON (untrusted input embedded in trusted envelope) |
| Hook process → stdout/stderr | One-way; only block decisions on stdout, only Class B errors on stderr |
| Env var $CLAUDE_PROJECT_DIR → ResolveWorkspaceRoot | Trusted (set by Claude Code) but treated defensively (verify markers exist) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering / Information Disclosure | fsutil.FileExists / LineCount when given a verdict-supplied path | mitigate | Wave 0 fsutil MUST: (a) reject absolute paths via filepath.IsAbs, (b) filepath.Clean then assert no leading "..", (c) treat any path containing ".." segment in cleaned form as rejected. Test cases in fsutil_test.go MUST include "../../etc/passwd", "/etc/passwd", "subdir/../../etc/passwd" — all reject. (Per RESEARCH.md Security Domain table line 1347.) |
| T-02-01-02 | DoS via huge JSON | Wave 2 will wrap stdin with io.LimitReader (1 MB); Wave 0 documents the cap in hooks/doc.go | mitigate | hooks/doc.go records "stdin is bounded to 1 MB via io.LimitReader; larger payloads → Class B exit 1". Implementation lands in Wave 2 (validate.go). |
| T-02-01-03 | Information Disclosure | Block-reason text leaking internal state | mitigate | decision.FormatViolation uses ONLY {ID, Path, Expected, Actual, Description} — never embeds raw source file contents, env vars, or workspace paths. Test in decision_test.go asserts the formatter output for a known violation contains exactly the expected substring set and nothing else. |
| T-02-01-04 | Spoofing | Agent emits agent_type = "go-taint-tracer" but is actually different | accept | Phase 2 trusts Claude Code's dispatch — the binary cannot independently authenticate the subagent. Risk accepted at the architecture layer; documented in hooks/doc.go. |
| T-02-01-05 | Symlink escape via fsutil.LineCount | Tampering / Information Disclosure | mitigate | fsutil.LineCount MUST os.Lstat first and reject if (info.Mode()&os.ModeSymlink) != 0. Test in fsutil_test.go creates a symlink fixture inside testdata/workspace/ pointing outside the workspace and asserts LineCount returns error. (Per RESEARCH.md Security Domain table line 1349.) |
| T-02-01-06 | DoS via deeply nested JSON | encoding/json is iterative; combined with 1 MB cap not a practical risk | accept | Documented in hooks/doc.go; no additional mitigation in Wave 0. |

    }

    const (
        modulePrefix = "github.com/saghaulor/claude-security-hooks/"
        allowedTest  = "github.com/google/go-cmp/"
    )
    type pkg struct {
        ImportPath string
        Standard   bool
        ForTest    string
    }
    for {
        var p pkg
        if err := dec.Decode(&p); err != nil {
            break
        }
        if p.Standard {
            continue
        }
        if strings.HasPrefix(p.ImportPath, modulePrefix) {
            continue
        }
        if strings.HasPrefix(p.ImportPath, allowedTest) {
            if p.ForTest == "" {
                t.Errorf("H5: %s imported by non-test code", p.ImportPath)
            }
            continue
        }
        t.Errorf("H5: disallowed dependency: %s (for-test=%q)", p.ImportPath, p.ForTest)
    }
}
