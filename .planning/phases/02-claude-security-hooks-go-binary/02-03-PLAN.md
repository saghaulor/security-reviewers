type TaintInput struct {

    Semgrep             SemgrepEvidence       `json:"semgrep"`
    Gopls               GoplsEvidence         `json:"gopls"`

    File           string  `json:"file"`
    Line           int     `json:"line"`
    Expr           string  `json:"expr"`
    Step           string  `json:"step"`

|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | T7 — agent claims it ran a tier different from input | mitigate | checkT7 directly compares verdict.Semgrep.Tier == input.SemgrepTier; mismatch emits Violation. Adversarial test case proves the mismatch is caught. |
| T-02-03-02 | Spoofing | Verdict claims `verdict="sanitized"` with no path | mitigate | T3 emits Violation when sanitized/exploitable verdict has empty path. Verbatim RESEARCH.md Pattern 4 test asserts this. |
