  <action>
    Create bootstrap/pre-flight-checks.sh as a bash script. The file must be executable (chmod +x will be run after creation). Use `#!/usr/bin/env bash` shebang. Set `set -euo pipefail` EXCEPT — do NOT use `set -e`; instead use explicit exit codes because the script needs to report multiple warnings before exiting.

    The script accepts TARGET_DIR as $1. If $1 is empty or unset, use `.`. Resolve TARGET_DIR to an absolute path using `TARGET_DIR="$(realpath "${1:-}")"` with fallback to `TARGET_DIR="$(realpath .)"`. Detect REPO_ROOT using `git rev-parse --show-toplevel 2>/dev/null || echo "$PWD"` from the script's invocation directory — this is used for repo-structure checks (not TARGET_DIR checks).

    Implement exactly these 6 checks in order. Each failure check must print to stderr a line beginning with "ERROR:" for hard failures or "WARNING:" for soft failures. After all checks, exit non-zero if any hard failure was recorded, exit 0 otherwise.

    Check 1 — Codegraph:
    - `command -v codegraph` must succeed. If not, print to stderr: "ERROR: codegraph not found. Install with: go install github.com/saghaulor/codegraph/cmd/codegraph@latest" and record hard failure. Do not exit immediately — continue checks.
    - If found, run `codegraph --version 2>&1` and print "OK: codegraph found at $(which codegraph)" to stdout.

    Check 2 — Make + Go + hooks module:
    - `command -v make` — if missing: "ERROR: make not found. Install build-essential or equivalent."
    - `command -v go` — if missing: "ERROR: go not found. Install from https://golang.org/dl/"
    - `[ -f "$REPO_ROOT/claude-security-hooks/go.mod" ]` — if missing: "ERROR: claude-security-hooks/go.mod not found. Are you running from the security_reviewer repo root?"
    - Each is a hard failure.

    Check 3 — Git + target repo:
    - `command -v git` — if missing: "ERROR: git not found."
    - `git -C "$TARGET_DIR" rev-parse --git-dir > /dev/null 2>&1` — if fails: "WARNING: $TARGET_DIR is not a git repository. code_ref will be empty."
    - Git absence is hard failure; non-git TARGET_DIR is a warning (not a hard failure).

    Check 4 — Go project structure in TARGET_DIR:
    - `[ -f "$TARGET_DIR/go.mod" ]` — if missing: "ERROR: $TARGET_DIR/go.mod not found. TARGET_DIR must be a Go module."
    - `[ -f "$TARGET_DIR/go.sum" ]` — if missing: "WARNING: $TARGET_DIR/go.sum not found. Run: go mod tidy"
    - go.mod absence is hard failure; go.sum absence is warning.

    Check 5 — Docker:
    - `command -v docker` — if missing: export DOCKER_AVAILABLE=false, print "WARNING: docker not found. govulncheck will use fallback mode."
    - If docker is found but `docker ps > /dev/null 2>&1` fails: export DOCKER_AVAILABLE=false, print "WARNING: docker daemon not running. govulncheck will use fallback mode."
    - If both succeed: export DOCKER_AVAILABLE=true, print "OK: docker available."
    - Docker failure is never a hard failure (govulncheck has {"available":false} fallback).

    Check 6 — Codegraph init + index with retry:
    - Only run if codegraph check (Check 1) passed.
    - Run `codegraph init "$TARGET_DIR" 2>&1`. If exits non-zero, print "WARNING: codegraph init failed: $output".
    - Run `codegraph index "$TARGET_DIR" 2>&1`. If exits non-zero:
      - Print "WARNING: codegraph index failed. Attempting retry after removing .codegraph/"
      - `rm -rf "$TARGET_DIR/.codegraph/"`
      - Re-run `codegraph init "$TARGET_DIR" 2>&1` and `codegraph index "$TARGET_DIR" 2>&1`.
      - If retry fails: "ERROR: codegraph index retry failed. Pipeline cannot proceed." and record hard failure.
    - If successful: print "OK: codegraph index complete."

    At the end: if any hard failures were recorded (use a FAILURES counter variable, incrementing with `((FAILURES++))` or POSIX `FAILURES=$((FAILURES+1))`), exit 1. Otherwise exit 0.

    Security: quote ALL variable expansions — "$TARGET_DIR", "$REPO_ROOT", "$output". Never unquoted.
  </action>
