```go
func checkT6(v *schema.TaintVerdict) []Violation {
    if v.Verdict == "input_mismatch" || v.Verdict == "ambiguous" {
        return nil
    }
    if v.Semgrep.Ran || v.Gopls.ReferencesCalls > 0 {
        return nil
    }
    return []Violation{{
        Path:     "semgrep+gopls",
        Expected: "semgrep.ran=true OR gopls.references_calls>0 (unless input_mismatch or ambiguous)",
        Actual:   "neither",
    }}
}
```

### New T-CodeRef joint invariant

Add to `TaintTracerJointInvariants`:

```go
{
    ID:          "T-CodeRef",
    Description: "if input has non-empty code_ref, verdict code_ref must match exactly",
    Severity:    SeverityHigh,
    Check:       checkTCodeRefJoint,
},
```

Implementation:

```go
func checkTCodeRefJoint(in *schema.TaintInput, v *schema.TaintVerdict) []Violation {
    if in.CodeRef == "" {
        return nil // non-git repo or pre-Phase-10 run: skip
    }
    if v.CodeRef != in.CodeRef {
        return []Violation{{
            Path:     "code_ref",
            Expected: in.CodeRef,
            Actual:   v.CodeRef,
        }}
    }
    return nil
}
```

**Why this matters:** A verdict produced against a different code version than the one being reviewed may cite line numbers that have since changed, reference functions that have been refactored, or report vulnerabilities that have already been fixed. `code_ref` mismatch is the signal that this has happened; the invariant ensures synthesis never aggregates such a verdict.
